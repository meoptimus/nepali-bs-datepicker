Nepali Datepicker — a Bikram Sambat date picker for jQuery

Pick dates in the Nepali calendar (बिक्रम संवत्) on any web page. Every view — days, months, years — is in BS, with built-in BS ↔ AD conversion, Devanagari or Latin digits, four themes, date ranges and keyboard navigation. It keeps the markup, options and events of bootstrap-datepicker, so its stylesheets and your existing code keep working.

नेपाली मिति छान्नका लागि jQuery डेटपिकर। BS र AD बीच रूपान्तरण, देवनागरी अङ्क, थिमहरू, र CDN बाट सिधै प्रयोग गर्न सकिने — बुटस्ट्र्याप-डेटपिकरको CSS सँग मिल्छ।

Use it in one minute

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@meoptimus/nepali-bs-datepicker@2.0.2/dist/css/bootstrap-datepicker3.standalone.min.css">
<script src="https://cdn.jsdelivr.net/npm/jquery@3.7.1/dist/jquery.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@meoptimus/nepali-bs-datepicker@2.0.2/dist/js/nepali-datepicker.min.js"></script>

<input id="dob">
<script>
  $('#dob').npdatepicker();                                   // 2083-07-14
  $('#dob').npdatepicker({ language: 'en', format: 'd MM yyyy' }); // 14 Kartik 2083
</script>

Or npm install @meoptimus/nepali-bs-datepicker. See the complete CDN example page.

Features

  • Bikram Sambat calendar from BS 1970 to 2100, verified month by month against the published Nepali calendar
  • Input values are BS dates in any format (yyyy-mm-dd, d MM yyyy, …); getDate() gives the AD Date
  • Nepali and English locales; Devanagari digits in the calendar, 0-9 in form values
  • Date ranges, multiple dates, month/year pickers, disabled and highlighted days, keyboard navigation
  • Themes: material, nepal, minimal, dark — or style it with any bootstrap-datepicker theme
  • Conversion API without a picker: $.fn.npdatepicker.calendar.toBS(date) / toAD(y, m, d)
  • Correct in every timezone; works with jQuery 1.12 to 4
