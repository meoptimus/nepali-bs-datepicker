Documentation

Nepali Datepicker is a Bikram Sambat (BS) datepicker for jQuery. It is a port of bootstrap-datepicker 1.10.1, so anything you know about that plugin applies here. This page covers what is different and what is new.

Getting started

You need jQuery (1.12 to 4.x), the plugin script, and one bootstrap-datepicker stylesheet. Themes are optional.

BS strings & Date objects

Strings are always Bikram Sambat dates written in the format option. JavaScript Date objects are always the equivalent Gregorian (AD) date.

APIAccepts / returns
input valueBS string, eg 2083-07-15 (Latin or Devanagari digits)
setDate(x)BS string, or AD Date
startDate, endDateBS string, or AD Date
datesDisabledarray (or comma-separated string) of BS strings
defaultViewDateBS string, AD Date, or {year, month, day} in BS with a 0-based month
getDate(), getDates()AD Date (local midnight)
getBsDate(), getBsDates(){year, month, day}, month 1–12
e.date / e.bsDateAD Date / {year, month, day}

Relative strings from bootstrap-datepicker also work: 'today', 'tomorrow', '+1m', '-2y', '+7d'. Months and years move in BS.

Date format

The format option controls both what is written to the input and how typed or pasted text is read.

m / mmMonth number7 / 07
M / MMMonth name, short / fullKar / Kartik · कार्तिक

$('#d').npdatepicker({ format: 'dd/mm/yyyy' });              // 15/07/2083
$('#d').npdatepicker({ format: 'DD, d MM yyyy', language: 'en' }); // Saturday, 15 Kartik 2083
$('#d').npdatepicker({ format: 'd MM yyyy' });                     // 15 कार्तिक 2083 (np locale)

For anything else pass { toDisplay: function (date, format, language) {…}, toValue: function (text, format, language) {…} }, exactly as in bootstrap-datepicker. Use $.fn.npdatepicker.calendar inside them to convert.

Events

$('#dob').npdatepicker().on('changeDate', function (e) {
  e.date;       // AD Date (local) or undefined when cleared
  e.dates;      // all selected AD Dates
  e.bsDate;     // {year: 2083, month: 7, day: 15}
  e.bsDates;    // all selected BS dates
  e.format();   // "2083-07-15" — also e.format('d MM yyyy') or e.format(index, format)
});
EventFired when
show / hideThe dropdown opens or closes.
changeDateThe selection changes (click, keyboard, typing, setDate).
clearDateThe selection becomes empty.
changeMonth / changeYear / changeDecade / changeCenturyThe visible BS month/year/decade/century changes; e.date is the new view date.
changeViewModeSwitching between days, months, years… views.

Conversion API

$.fn.npdatepicker.calendar converts between calendars without a picker. All months are 1–12.

var cal = $.fn.npdatepicker.calendar;

cal.toBS(new Date(2026, 9, 31));   // {year: 2083, month: 7, day: 15}
cal.toAD(2083, 7, 15);             // Sat Oct 31 2026 00:00 (local)
cal.today();                       // today in BS
cal.isValid(2083, 4, 32);          // false
cal.daysInMonth(2083, 3);          // 32
cal.daysInYear(2083);              // 365
cal.range();                       // {minYear: 1970, maxYear: 2100}
cal.getYear(2083);                 // [31, 31, 32, 31, 31, 30, 30, 30, 29, 30, 30, 30]
cal.setYear(2100, [...12 numbers]);  // append or correct a year
cal.extend({2100: [...], 2101: [...]});

// Formatting and parsing helpers (internal dates are UTC midnight)
var D = $.fn.npdatepicker.DPGlobal;
D.formatDate(new Date(Date.UTC(2026, 9, 31)), 'd MM yyyy', 'np', true);  // "१५ कार्तिक २०८३"
D.parseDate('15/07/2083', 'dd/mm/yyyy', 'en');                          // Date (UTC midnight)

toBS and toAD return null for dates outside the table.

Unicode (Devanagari) digits

unicodeDigitsCalendar showsInput value
true (default)१ २ ३ … २०८३2083-07-15
false1 2 3 … 20832083-07-15

The input value, getFormattedDate() and e.format() always use 0-9 whatever the setting, so form data stays machine-readable. Typing or pasting Devanagari digits is accepted and converted. Only locales with a digits array are affected, so the setting does nothing with language: 'en'. Switch at runtime with $(el).npdatepicker('setUnicodeDigits', false).

Custom theme

Every theme is a set of CSS custom properties. Tweak one by overriding its variables:

.npdatepicker-theme-nepal {
  --npdp-head-bg: #0b6e4f;
  --npdp-accent: #0b6e4f;
}

To add a new theme to the project, create src/themes/<name>.css with the variables below and run npm run build; the shared rules are generated for it.

Styling your own day classes

Theme rules are deliberately specific so they beat bootstrap-datepicker's CSS. To colour classes you add with beforeShowDay, set the theme variables on the cell as well — they win under every theme:

.datepicker td.day.holiday:not(.active) {
  color: #c8102e;           /* without a theme */
  --npdp-text: #c8102e;     /* with any theme */
  --npdp-hover-bg: #fde8ec;
}

Prefer plain CSS? The picker has the class npdatepicker and uses bootstrap-datepicker's class names (.day, .active, .today, .range, .disabled…), so any bootstrap-datepicker theme works as well.

Updating calendar data

BS month lengths are announced each year by the Nepal Panchanga Nirnayak Samiti, and years in the future are projections. All of the data is one table at the top of src/nepali-datepicker.js:

years: {
    // Year: [Bai, Jes, Asa, Shr, Bha, Ash, Kar, Man, Pou, Mag, Fal, Cha]
    2083: [31, 31, 32, 31, 31, 30, 30, 30, 29, 30, 30, 30],
    …
}
  1. Edit a row to correct a year, or append a row for a new year (years must be contiguous).
  2. Run npm test: the table is validated and every day is round-tripped.
  3. Run npm run verify-calendar -- <year> to compare with hamropatro.com, then npm run build and release.

Need a fix before the next release? Patch it at runtime, before creating pickers:

$.fn.npdatepicker.calendar.setYear(2084, [31, 31, 32, 32, 31, 30, 30, 29, 30, 29, 30, 30]);

Compatibility

  • jQuery 1.12 to 4.x; all evergreen browsers. The script is ES5.
  • Correct in every timezone: dates are calendar days, not instants.
  • Can run next to bootstrap-datepicker: it uses $.fn.npdatepicker, data('npdatepicker'), data-provide="npdatepicker" and the .npdatepicker event namespace.
  • $.fn.npdatepicker.noConflict() restores a previous $.fn.npdatepicker.

Migrating

From bootstrap-datepicker

Replace .datepicker( with .npdatepicker( and data-provide="datepicker" with data-provide="npdatepicker". Strings you pass (input values, startDate…) are now BS dates; Date objects keep meaning AD dates.

From the in-house v1 (v1.js)

  • The NepaliFunctions script is no longer needed; remove it.
  • getDate() now returns a real AD Date; use getBsDate() or e.format() for the BS value.
  • The default format is yyyy-mm-dd, which matches what v1 wrote.
