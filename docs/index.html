Bikram Sambat datepicker for jQuery

Every view is in the Nepali calendar, with BS ↔ AD conversion built in. It keeps bootstrap-datepicker's markup, options and events, so its stylesheets and your existing code keep working.

Get started Use from CDN
Applies to every demo on this page

Basics

Inputs, components and inline calendars, in Nepali or English.

Input

Defaults: Nepali UI, yyyy-mm-dd, today highlighted, closes on select.

English locale & custom format

Month names in English, any combination of format tokens.

Latin digits in the calendar

unicodeDigits: false shows 1 2 3 instead of १ २ ३. The input value is always 2083-07-15; typing २०८३-०७-१५ is converted.

Component with buttons

Add-on opens the picker; Today selects today, Clear empties it.
